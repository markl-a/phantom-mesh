# Evolve Goals — phantom-mesh

This file is the curated milestone queue that drives `phantom autoevolve
--goals`. Edit it freely: any line not matching `- [ ]` / `- [x]` is
preserved on round-trip, so notes and section headers stay put.

**Pick goals small enough to ship in one commit.** "Add HMAC rotation
endpoint with one test" is right-sized; "rebuild the cluster manager" is
not. Big goals belong in MASTER-PLAN.md, then get sliced into entries here.
