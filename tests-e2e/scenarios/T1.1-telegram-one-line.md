# T1.1 — Telegram 一句話 → 跑指令

**Source**: doc 28 §2 Tier 1 + doc 29 §4 **V3**(Telegram production-default)
**Status**: 🔴 等 BotFather token

## Prereqs
- [ ] spectyn binary verified via `scripts/verify-binary.sh <bin> --quick`
- [ ] LLM provider key in `~/.spectyn-mesh/env` or `agents.toml`
- [ ] BotFather token in env: `export TELEGRAM_BOT_TOKEN="..."`
- [ ] `~/.spectyn-mesh/agents.toml`: `[telegram] allowed_users = ["<your-tg-id>"]`
- [ ] Telegram app installed on your phone, signed in

## Steps
1. 開 daemon:
   ```bash
   spectyn serve --openclaw-telegram --bot-token-env TELEGRAM_BOT_TOKEN
   ```
2. 確認 banner 出現 `openclaw  : telegram bot ENABLED (allowlist=N ids)`
3. 在手機 Telegram:搜尋你的 bot username → `/start`
4. bot 回:`◆ Welcome to your Spectyn Mesh` + persona binding 確認
5. 傳一則:`summarise the README in current workspace`
6. 觀察 bot 在 5-30 秒內回覆

## Pass criteria
- [ ] `/start` 後 5 秒內收到 binding 確認
- [ ] 傳訊息後 30 秒內收到合理回覆(不超時、不錯誤)
- [ ] spectyn log 顯示 `tool_call: fs:read(README.md)` 之類
- [ ] SQLite 持久化記錄存在 `~/.spectyn-mesh/telegram.db`(或同等 path)

## Failure modes
- bot 不回 → 多半是 `allowed_users` 沒設你的 user id
- 401 Unauthorized → token 錯
- 連 30 秒都不回 → LLM provider 慢 / 沒 key
