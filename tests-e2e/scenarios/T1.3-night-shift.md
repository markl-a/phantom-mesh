## Prereqs
- [ ] phantom service installed (`phantom service install`)
- [ ] LLM provider key 設好
- [ ] (可選)Telegram bot 跑著(從手機接結果用)

## Steps
1. ```bash
   phantom autoevolve schedule install --interval 3600 --target check --max-rounds 5
   phantom autoevolve schedule status        # 確認註冊成功
   ```
2. 等下一個整點觸發,或手動觸發測試:
   ```bash
   phantom autoevolve --once --target check --max-rounds 5
   ```
3. 觀察 log:
   ```bash
   phantom autoevolve log --n 5
   ```

## Pass criteria
- [ ] schedule status 顯示 `registered : yes`
- [ ] autoevolve log 至少 1 行,exit 綠
- [ ] 若 V3 也跑 → Telegram 收到「done」通知

## Win-specific 確認

Get-ScheduledTask -TaskName "PhantomAutoevolve"
```
應該顯示 Ready / Running 狀態。

## Mac-specific 確認
```bash
launchctl print gui/$(id -u)/ai.phantommesh.autoevolve | grep state
```

## Linux-specific 確認
```bash
systemctl --user status phantom-autoevolve.timer
```
