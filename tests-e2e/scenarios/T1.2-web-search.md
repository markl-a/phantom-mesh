# T1.2 — Web search + 摘要回手機(或 stdout)

**Source**: doc 28 §2 Tier 1 + doc 29 §4 **V1**(30 tools + 12 providers)
**Status**: 🟢 可跑(LLM key 在即可)

## Prereqs
- [ ] spectyn binary verified (`verify-binary --quick`)
- [ ] 至少 1 個 provider key 設好(Anthropic / Groq / Mistral / etc.)

## Steps(headless)
1. ```bash
   spectyn exec "search the web for the top 3 Hacker News posts about Tailscale this week, return as a markdown table" --json
   ```
2. 觀察 `--json` stream 出現:
   - `StreamStart`
   - `ContentBlock`(LLM 回應)
   - 至少 1 個 `ToolCall { name: "web_search", ... }`
   - `ToolResult` 含真實 URL(非編造)
   - `Done` event

## Steps(Telegram,需先做 T1.1)
1. 傳手機:`search the web for the top 3 HN posts about Tailscale`
2. 等 bot 回覆(可能含 streaming partial)
3. 點 URL 確認真實可達

## Pass criteria
- [ ] 至少 1 個 web_search tool_call 被觸發
- [ ] 回應含至少 3 個來源 URL
- [ ] URL 確認真實可達(curl -I 200 OK)
- [ ] 沒有「假的」hallucinated URL

## Variation:測 12 個 provider 各一次(V1 完整驗收)
```bash
for prov in anthropic openai groq mistral xai together fireworks cohere perplexity ai21 nvidia mlx; do
  echo "=== $prov ==="
  spectyn exec "say hello in one word" --json --quiet | jq -r 'select(.tag=="Done") | .output'
done
```
- 12/12 通過 = V1 翻 🟢
- MLX 那行只在 m1 上跑通(macOS only)
