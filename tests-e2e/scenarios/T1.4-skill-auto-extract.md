# T1.4 — Skill 自動萃取(Curator 學習迴圈)

**Source**: doc 28 §2 Tier 1 + doc 29 §4 **V2**(Curator skill loop + FTS5)
**Status**: 🟡 等 `experimental-curator` production-default ON

## Prereqs
- [ ] spectyn built with `--features experimental-curator`(v0.6.0 production-default ON 後可省)
- [ ] `spectyn autoevolve schedule` 排程跑著
- [ ] LLM provider key 設好
- [ ] (推薦)Telegram bot 跑著,從手機重複 3 次任務最快

## Steps(需要跨至少 24h,因為要等 nightly cron)

### Day 1
1. 從 Telegram(或 TUI / exec)連續 **3 次** 跑同樣的任務,**都成功**。例:
   - 「list all .md files in D:/Projects/goal_plan/docs and show the first 3 lines of each」
2. 確認 3 次都回 `ok` 且結果一致
3. 等到 02:00(nightly cron 預設時間)

### Day 2 早上
4. ```bash
   spectyn skill list
   ```
5. 觀察新增的 skill,e.g. `list-markdown-files-preview`(名稱由 Curator 自動 derive)

## Pass criteria
- [ ] `spectyn skill list` 顯示至少 1 個新 skill
- [ ] skill `.md` 文件存在 `~/.spectyn-mesh/skills/`
- [ ] FTS5 search 可找到:`spectyn evolve --extract-threshold 5`(預期看到 skill metadata)
- [ ] skill 內 metadata 含原任務的 trajectory 摘要

## Speed-up:跳過 cron,直接 trigger 萃取
```bash
spectyn evolve --extract-skills --extract-threshold 7 "<same prompt as 3-time test>"
```
應該直接看到萃取邏輯啟動 + skill 寫進 `~/.spectyn-mesh/skills/`。
