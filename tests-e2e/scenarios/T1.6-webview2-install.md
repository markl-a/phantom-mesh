# T1.6 — WebView2 自動安裝(Windows 限定)

**Source**: doc 28 §2 Tier 1 + doc 29 §4 **V6** + doc 25 **P-WIN-2**
**Status**: 🟡 v0.6.0 規劃中

## Prereqs
- [ ] **乾淨 Windows VM**(或乾淨重灌 Win 機)— 沒裝過 WebView2 runtime
- [ ] 從 GitHub Releases 下載最新 spectyn Windows binary,或用 install-one-liner

## Steps
1. 確認 WebView2 確實沒裝:
   ```powershell
   Get-AppxPackage Microsoft.WebView2Runtime -ErrorAction SilentlyContinue
   # 預期空
   reg query "HKLM\SOFTWARE\WOW6432Node\Microsoft\EdgeUpdate\Clients\{F3017226-FE2A-4295-8BDF-00C3A9A7E4C5}" /v pv 2>&1
   # 預期 "ERROR: The system was unable to find..."
   ```
2. 跑 spectyn(預期 Tauri app 啟動,因為 spectyn 本身 TUI 不需要 WebView2;Tauri desktop app 才需要):
   ```powershell
   # 啟動 Tauri desktop app(若已 ship)
   & "C:\Program Files\Spectyn Mesh\spectyn-mesh.exe"
   ```
3. 觀察:
   - 應該彈出「正在安裝 WebView2 runtime ...」進度條(由 spectyn installer 觸發)
   - 等下載完(<2 分鐘,網路要 OK)
   - app 啟動 + 主畫面顯示

## Pass criteria
- [ ] WebView2 runtime 被自動裝(下載 + 安裝完)
- [ ] spectyn Tauri app 主畫面正常顯示
- [ ] 第二次跑(已裝 WebView2)直接啟動,不重複 install

## Note
這個場景**需要乾淨 Win 11 VM 或新 ROG/node-b 機**。node-a 上已經有 WebView2,**無法在 node-a 本機驗證**。
建議在 node-a onboard 時當「乾淨 Win VM」做驗收。
