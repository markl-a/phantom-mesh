# T1.8 — TUI 渲染壓測(縮放 + 長輸出 + ratatui Clear)

**Source**: doc 28 §2 Tier 1 + doc 29 §4 **V11**(TUI render correctness)
**Status**: 🟡 等 V11 4 個分支 merge

## Prereqs
- [ ] phantom binary verified
- [ ] **真實 terminal**(Windows Terminal / iTerm2 / kitty / alacritty)— 不能是 conhost
- [ ] LLM provider key 設好

## Steps
1. 開 TUI:
   ```bash
   phantom tui
   ```
2. 視窗最大化
3. 從 input pane 打:
   ```
   list all .md files in D:/Projects/goal_plan/docs and show the first 5 lines of each
   ```
   (Win 改 `D:\Projects\...`,Mac/Linux 改 `~/Projects/...`)
4. Enter 送出
5. **趁 streaming 中**(transcript pane 正逐字長出):
   - 縮放視窗 → 左半邊(Win+Left)
   - 縮放視窗 → 右半邊(Win+Right)
   - 縮放視窗 → 還原(Win+Up)
6. 等 streaming 完成
7. PageUp / PageDown 滾動 transcript
8. 切 agent(Tab × 3)
9. `/sidebar` 切隱顯
10. `/copy last`(複製最後一輪)

## Pass criteria
- [ ] **無殘影**(縮放後沒有上次內容卡在 transcript)
- [ ] **無 ratatui Clear 錯誤**(視窗內整片清乾淨)
- [ ] **無 paragraph line-count 錯位**(transcript 不會吃掉部分 input pane)
- [ ] **無 stale cell**(resize 後字元位置正確)
- [ ] streaming 過程中縮放,不會 crash 或卡住
- [ ] `/copy last` 真的 copy 到剪貼板(用其他 app 貼上驗證)
- [ ] PageUp/PageDown 滾動順暢、不掉 frame
- [ ] Tab 切 agent 後 status bar 正確更新

## 已知失敗(預期會看到)
- conhost(Win 預設):`/mouse on` 後選取不 work — 這是 conhost 限制,**不算 V11 失敗**
- xterm 老版:emoji 顯示為 ▢ — 同上

## Failure modes(若失敗)
- 殘影 → ratatui Clear widget 沒在 resize 時呼叫 → 報 V11 bug
- 字元位置錯 → paragraph wrap 用了錯誤的 cell-width(中日韓字元寬度問題)
- crash → 在 streaming + resize 同時發生的 deadlock → 記下重現步驟報 bug
