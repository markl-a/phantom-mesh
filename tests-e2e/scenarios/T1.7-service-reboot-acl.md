# T1.7 — Service install + 重開機 auto-start + auth.json ACL

**Source**: doc 28 §2 Tier 1 + doc 29 §4 **V7**(Curator memory 持久化)+ doc 25 **P-WIN-4**
**Status**: 🟡 Win ACL hardening v0.6.0;Linux/Mac 🟢

## Prereqs
- [ ] phantom binary 在 PATH
- [ ] OS 啟動行為設好(Linux:`loginctl enable-linger`;Mac:預設;Win:Scheduled Task)

## Steps(Windows)
1. **Admin PowerShell** 跑:
   ```powershell
   phantom service install              # 建 Scheduled Task "PhantomMesh"
   phantom service status                # 應顯示 registered: yes
   ```
2. 設 Telegram bot 環境變數(寫進 user env / 或 service Wrapper env):
   ```powershell
   [Environment]::SetEnvironmentVariable("TELEGRAM_BOT_TOKEN", "1234:abc...", "User")
   ```
3. 從手機 Telegram 跑一個任務,確認可用
4. **重開機**
5. 重開機後:
   - 手機 Telegram 再傳訊息(不需手動跑 phantom)
   - 應該 5-30 秒內收到回覆
   - 確認 `Get-Process phantom` 看到 process 跑著
   - 確認 auth.json 權限:
     ```powershell
     icacls "$HOME\.phantom-mesh\auth.json"
     # 預期:只有 BUILTIN\Administrators + 當前 user 有讀寫;不該有 Everyone / Users 群組
     ```

## Steps(Linux)
1. ```bash
   phantom service install
   sudo loginctl enable-linger $USER    # 沒這個重開機後 service 不會自啟
   systemctl --user status phantom-mesh
   ```
2. 設 token + 跑 Telegram
3. **重開機**
4. 重開機後驗證:
   ```bash
   systemctl --user status phantom-mesh    # active (running)
   ls -la ~/.phantom-mesh/auth.json         # 0600(只有 owner 讀寫)
   ```

## Steps(macOS)
1. ```bash
   phantom service install                  # LaunchAgent
   launchctl list ai.phantommesh.app
   ```
2. 設 token + 跑 Telegram
3. **重開機**(或 `launchctl bootout` 再 `launchctl bootstrap`)
4. 驗證:
   ```bash
   launchctl list | grep phantommesh
   ls -la ~/.phantom-mesh/auth.json
   ```

## Pass criteria
- [ ] 重開機後 service 自啟(無需手動跑)
- [ ] Telegram bot 重開機後第一個訊息也能回(< 60 秒)
- [ ] auth.json 權限:Unix 0600 / Win 只 current user + Admin
- [ ] token / API key **沒洩漏**到 process list(`ps` 看不到明文)
