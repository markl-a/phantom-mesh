- Windows linker LNK1104 — kill stale clawtex-core.exe before rebuild
- Use checked_sub for Instant arithmetic on Windows
- SQLite :memory: creates separate DB per connection — use tempfile for persistence tests
- Tools implement Tool trait: name(), description(), parameters_schema(), execute()
- Provider implements Provider trait: name(), chat(), stream_chat(), supports_streaming(), supports_native_tools()
- SecurityConfig has workspace_dir, rate_limit — clone for tool constructors
- Memory tools need Arc<MemoryStore> — register after MemoryStore creation, before Arc<ToolRegistry>
- ToolRegistry::register() adds tools dynamically after initial construction
- agents.toml is the central config file at ~/.clawtex/agents.toml
