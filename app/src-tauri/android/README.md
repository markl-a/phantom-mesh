# app/src-tauri/android — tracked custom Android code

> **Why this dir exists**: `app/src-tauri/gen/android/` is **gitignored** (full
> Tauri mobile project, regenerated by `tauri android init`). Custom Kotlin or
> resources written directly into `gen/android/` are **never version controlled**
> and get **wiped on regeneration**.
>
> Discovered 2026-05-28: `MeshNodeService.kt` + the Quick Settings tile were only
> in the gitignored `gen/` dir → not tracked. This dir is the tracked home.

## Layout

```
android/
├── inject.sh                    ← copies everything below into gen/android before build
├── kotlin/                      ← custom Kotlin (→ gen/android/app/src/main/java/ai/phantommesh/app/)
│   ├── MainActivity.kt           TauriActivity override — SPEC-34 §10D system-back bridge
│   ├── MeshNodeService.kt        specialUse foreground node + SPEC-21 focus host + habit-tap queue
│   ├── FocusQuickTile.kt          SPEC-34 §10E Quick Settings focus tile (live countdown)
│   ├── FocusSessionState.kt      shared focus-session state (prefs FSM)
│   ├── FocusUpkeepWorker.kt       WorkManager stale-focus cleanup (no FGS)
│   ├── HabitChipPaletteWidget.kt  SPEC-34 §10E Glance habit widget → capture queue
│   └── BootReceiver.kt            re-arm upkeep + best-effort restart node on reboot
└── res/
    ├── drawable/ic_focus_tile.xml
    ├── xml/habit_chip_palette_widget_info.xml  ← Glance appwidget-provider
    ├── values/strings-phantom.xml   ← becomes gen/android/.../res/values/strings.xml
    ├── values/colors.xml            ← SPEC-02 phantom tokens (→ res/values/colors.xml)
    ├── values/themes.xml            ← Material 3 theme (→ res/values/themes.xml)
    └── values-night/themes.xml      ← dark variant (→ res/values-night/themes.xml)
```

## Build flow

```bash
npm run tauri android init                 # once — creates gitignored gen/android/
bash app/src-tauri/android/inject.sh       # inject tracked custom code
npm run tauri android build                # build APK (needs Android SDK)
# emulator test runs on ayaneo (Android primary) — mac only writes code
```

`inject.sh` is idempotent — re-run after every `tauri android init` / regen.

## Adding new custom Android code

1. Put `.kt` in `kotlin/`, resources in `res/`
2. If it needs a manifest entry, extend the manifest-patch block in `inject.sh`
3. Commit — it's tracked here, survives regen
