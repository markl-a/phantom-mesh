> **資料根隔離（`SPECTYN_HOME`，跑前先設）**：本檔凡會寫入資料根的可執行步驟一律引用 `${SPECTYN_HOME:-$HOME/.spectyn-mesh}`，先 `export SPECTYN_HOME="$(mktemp -d)/.spectyn-mesh"` 即可讓測試落在 sandbox、不污染真實家目錄；未設則 fallback 到實機現行路徑 `~/.spectyn-mesh`。
> **⚠️ drift 註**：`SPECTYN_HOME` 是 SPEC'd data-root override，但 **as-built 尚未被 home-resolver honor** —— `core/src/config.rs:380-381` 仍以 `dirs::home_dir().join(".spectyn-mesh")` 解析資料根，`core/src/tui.rs:8927/8930` 明標「needs SPECTYN_HOME resolver」為 tracked follow-up（#322 home-resolver 統一）。因此下文「備註/預期」欄中描述 binary **實際**寫入位置的敘述（例如 `~/.spectyn-mesh/keys`、`~/.spectyn-mesh/events`、`~/.spectyn-mesh/crashes`、`~/.spectyn-mesh/peers.json`）刻意保留實機真相、未改寫成變數；待 #322 落地後 binary 才會真正改寫到 `$SPECTYN_HOME`，屆時敘述與 fallback 一併收斂。
