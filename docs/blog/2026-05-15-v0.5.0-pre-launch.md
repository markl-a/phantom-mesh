# phantom-mesh v0.5.0-pre：交付了什麼、還沒交付什麼，以及它在 2026 年 agent（代理）生態中的定位

*2026-05-15 — 草稿，標記為 `v0.5.0-pre`，晉升為 `v0.5.0` 取決於三項由操作者（operator，操作者）提供的證據。*

## 剛剛交付了什麼

在單一週末的衝刺中，我們對 `main` 合入了十個 PR（Pull Request，拉取請求）：六條 best-effort（盡力而為）軌道全數合併（6/6）、五條 hard-gated（硬性把關）軌道中有兩條在程式碼審查通過後合併（2/5），另外三條被擋下——不是因為程式碼壞了，而是因為它們需要只有真實硬體上的人類操作者才能產生的證據。執行環境（runtime，執行環境）現在具備了自動快取的 Anthropic SDK、一個藏在 feature flag（功能旗標）後的 Curator（策展者）骨架、十個全新的 Hermes 風格工具、一個可插拔的聊天平台 channel trait（頻道特徵介面），以及 Android worker（工作節點）能力公告。此標籤是位於 `722da5b` 的 `v0.5.0-pre`；晉升為 `v0.5.0` 是有條件的，並非自動。

## 差異化優勢（老實說）

phantom-mesh 已不再是唯一的 Rust + P2P（點對點）+ agent 執行環境。那道護城河（moat，護城河）已經消失——[OpenFang](https://github.com/RightNow-AI/openfang)（MIT 授權、約 16.8K 星、Rust + 自家 HMAC-SHA256 P2P + MCP + A2A）交付了相同的形態，且有更廣的協定支援與更大的社群。OpenFang 在 A2A 協定的覆蓋面與 scheduled-agent（排程代理）成熟度上勝過我們。我們則在 mobile-native（行動原生）上勝過 OpenFang：一個已簽章的 Tauri APK、一個已簽章的 IPA、一個在 Android 上真實運行的 Termux worker，以及在每個受支援作業系統上作為 closed-loop（閉迴路）自我修復的 `phantom evolve`。

[Hermes Agent](https://github.com/NousResearch/hermes-agent)（NousResearch、MIT 授權、Python）是我們這個週末移植到 Rust 的 Curator + Skill Document（技能文件）+ FTS5 記憶體模式的架構參考。Hermes 擁有多年的 Curator 調校與一個真正的 Honcho 辯證式（dialectic）使用者模型；我們擁有的是一個骨架。其姊妹倉庫 `hermes-agent-self-evolution` 沒有 LICENSE（授權檔），所以我們借鑑了模式，但從未取用程式碼。

[OpenCode](https://github.com/sst/opencode)（sst、MIT 授權、TypeScript、約 160K 星）是互補而非競爭——一個具備一流 TS 外掛 API 的程式撰寫代理。我們可以成為 OpenCode 使用者的 provider（供應方）外掛，而 OpenCode 也能以無介面（headless）方式被當作 phantom subagent（子代理）呼叫。

[Apple Foundation Models](https://developer.apple.com/documentation/foundationmodels)（iOS/macOS 26、裝置端約 3B 參數的 LLM、Swift API）對純 Apple 使用者而言，吃下了「在 iOS 上自帶本地 LLM」這個賣點。我們在 iOS 上剩下的切入角度是跨裝置同步、非 Apple 的供應方、大於 3B 參數的模型，以及在 app 暫停（suspension）之間維持 agent-loop（代理迴圈）的持久性。

## v0.5.0-pre 有哪些新東西

**Anthropic SDK 升級——自動 prompt caching（提示快取）**（[#31](https://github.com/markl-a/phantom-mesh/pull/31)，正式路徑，無旗標）。Claude provider 現在每個 session（工作階段）發出單一個 `cache_control` 斷點；其餘由 Anthropic 託管的快取自動接手。已在第二次呼叫時驗證：`cache_read_input_tokens > 0`。額外功能：Opus 4.7+ 的 `thinking.display: "omitted"`（保留簽章、從串流中丟棄區塊），且所有舊式 `anthropic-beta: tool-use-2024-*` 標頭都已移除，因為 tool-use（工具使用）現已 GA（正式上線）。

**閉迴路自我改進骨架**（[#33](https://github.com/markl-a/phantom-mesh/pull/33)，藏在 `experimental-hermes-curator` 後）。`phantom evolve --judge` 現在會做一次真正的 Anthropic 往返呼叫，並把分數寫入 `EvolveCheckpoint`。這是一個策展／淘汰迴圈的種子，而非迴圈本身——設計意圖是一個 7 天的 cron（定時排程），根據累積的評審分數來晉升／淘汰技能，類似 Hermes Curator。今天它評分；明天它行動。

**Hermes 風格的工具目錄**（[#27](https://github.com/markl-a/phantom-mesh/pull/27)，藏在 `experimental-hermes-tools` 後）。Hermes 目錄中排名前十的工具被移植到 Rust，成為一個可擴充的 trait。設計上將在 v0.6.0 成長到 20+ 個。配套變更：Skill Document JSON schema（JSON 結構描述）+ 解析器（[#29](https://github.com/markl-a/phantom-mesh/pull/29)）、帶有遷移檔 `0007_hermes_fts5.sql` 的 FTS5 SQLite 記憶體後端（[#30](https://github.com/markl-a/phantom-mesh/pull/30)），以及 4 個新供應方——Mistral、xAI、Together、Fireworks（[#25](https://github.com/markl-a/phantom-mesh/pull/25)，藏在 `experimental-hermes-providers` 後）。

**聊天平台的可插拔 channel 架構**（[#26](https://github.com/markl-a/phantom-mesh/pull/26)，藏在 `experimental-openclaw` 後，外加 [#28](https://github.com/markl-a/phantom-mesh/pull/28) 用於 Telegram）。一個 `Channel` trait，加上會回傳 `Err("not yet implemented")` 的 WhatsApp 與 Slack 樁（stub，存根）——刻意不造假。Telegram 轉接器（adapter）已程式完成並藏在 `experimental-openclaw-telegram` 後，在合併前等待一次真正的 BotFather 往返驗證。

**Android worker 能力公告**（[#32](https://github.com/markl-a/phantom-mesh/pull/32)，程式碼審查通過，等待硬體驗證）。`worker_caps` 由 Android 用戶端公告；`core/src/dispatch.rs` 強制執行能力匹配，因此鎖定某項 worker 不具備之能力的任務，會在 dispatch（派送）時被拒絕。硬性把關是一份來自任何搭載 Termux 的 aarch64 Android 裝置的真實裝置端日誌（該協定記錄於 `mobile/android/README.md`；已測試裝置包含 ROG Phone 6——我們最初的參考裝置——以及一台 Samsung Galaxy Tab S8+ 與一個透過 [#155](https://github.com/markl-a/phantom-mesh/pull/155) CI 替代方案運行的 Pixel 7 AVD），日誌顯示能力已公告、不匹配的任務被拒絕、匹配的任務以一個 `dispatch_id` 被接受。

## v0.5.0 中沒有什麼

老實說。完整的 Hermes 對等（40-70+ 個工具、18-25 個供應方、GEPA 提示演化）還需要 4-8 週，不在此次切版中。WhatsApp 與 Slack 的 channel 實作明確就是樁——Meta Business 與 Slack 的驗證是 1-3 週的外部阻塞因素。Curator 迴圈是一個骨架加上單一個 LLM 評審，而非具備持久性與 cron 的正式穩定演化迴圈。Honcho 辯證式使用者建模不在範圍內。iCloud 同步延後。A2A 協定支援在路線圖上，尚未交付。

## 如何試用

```bash
git clone https://github.com/markl-a/phantom-mesh
cd phantom-mesh/core
cargo run --features experimental-hermes-curator,experimental-hermes-tools,experimental-hermes-memory,experimental-hermes-providers,experimental-openclaw -- onboarding
```

所有 experimental（實驗性）功能預設為關閉。穩定的介面（自動 prompt caching、驗證通過後的 Android dispatch 過濾器）不需要旗標。這個單一執行檔仍可在 Mac、Windows、Linux、Android（Termux + Tauri APK）與 iOS（側載 IPA）上安裝並運行——完整的生態系地圖見 [docs/positioning.md](../positioning.md)。
