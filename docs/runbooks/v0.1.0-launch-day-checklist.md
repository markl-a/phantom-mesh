## 4. Per-platform binary distribution (09:30 → 11:30) [SPEC-FREEZE-V1 §6.3 critical path]

v0.1.0 ships per-host manual builds (GitHub Actions release matrix is
v0.2 work). Each build host produces its artefact, which gets attached
to the GitHub release.

```bash

./scripts/build-mac.sh
ls -la dist/phantom-aarch64-apple-darwin   # ~20MB, signed

# 4.2 iOS IPA build (this session, after APPLE_TEAM_ID set)

#     cross-mesh dispatch from Mac):

# Z13 returns the artefacts; SCP them back via Tailscale:
scp m4932@100.87.70.65:.phantom-mesh/dist/phantom-x86_64-pc-windows.exe dist/
scp m4932@100.87.70.65:.phantom-mesh/dist/phantom-mesh-android.apk      dist/

# 4.4 Oracle Cloud A1 builds Linux ARM (Oracle session)
phantom dispatch --on oracle "cd ~/repos/phantom-mesh && ./scripts/build-linux.sh"
scp ubuntu@<oracle-tailscale>:~/repos/phantom-mesh/dist/phantom-aarch64-unknown-linux-gnu dist/

# 4.5 Verify every binary's `--version` reports v0.1.0 with same core_sha
for f in dist/phantom-*; do
  echo "=== $f ==="
  file "$f" | head -1
done

# 4.6 Upload to GitHub release (v2 will automate via Actions release matrix)
gh release create v0.1.0 \
  --title "phantom-mesh v0.1.0" \
  --notes-file CHANGELOG.md \
  --draft \
  dist/phantom-aarch64-apple-darwin \
  dist/phantom-mesh-ios.ipa \
  dist/phantom-x86_64-pc-windows.exe \
  dist/phantom-aarch64-unknown-linux-gnu \
  dist/phantom-mesh-android.apk

# 4.7 Sign each artefact with maintainer key (post-v0.1.0; v0.1.0 ships
#     ad-hoc-signed only on macOS, unsigned elsewhere)
# (skip in v0.1.0; signed releases are v0.2)

# 4.8 Promote release from draft → published
gh release edit v0.1.0 --draft=false
```
