## 定價哲學與總體原則

### 核心公式

```
你的定價 = 客戶感知價值 × 0.1~0.3
（不是你的成本 + 利潤率）
```

Clawtex 的殺手級優勢是**幾乎零邊際成本**（本地推理電費 ~NT$300-400/月），這意味著：

1. **不要按成本定價** — 你的成本趨近於零，但客戶價值不是零
2. **按結果定價** — 客戶省下的時間、賺到的錢、避免的風險
3. **價格錨定** — 永遠先展示「沒有你他們要花多少」

### 三大定價心理學原則

| 原則 | 說明 | 實踐 |
|------|------|------|
| **價格錨定** | 先展示高價選項，讓中價看起來合理 | 每個產品至少 3 個定價層 |
| **Charm Pricing** | $49 比 $50 感覺便宜很多 | 所有價格用 9 結尾 |
| **損失規避** | 「你每月損失 NT$30,000」比「你每月能省 NT$30,000」有效 2 倍 | 銷售文案強調損失 |

### Clawtex 特有成本優勢

| 項目 | Clawtex 成本 | 雲端競品成本 | 優勢倍數 |
|------|------------|------------|---------|
| 每 1M tokens 推理 | ~NT$0（本地） | NT$15-450（雲端 API） | **無限大** |
| 電費/月 | NT$300-400 | N/A | - |
| 雲端 API 備援/月 | NT$3,000-15,000 | NT$30,000-150,000 | **10x** |
| 每次 Hand 執行 | ~NT$0-3 | NT$15-50 | **5-50x** |

- Prompt Engineering：$200-500/hr
- AI 相關工作者比非 AI 工作者收入**高 44%**

### 快速建立收費信心策略

```
Week 1-2: 2-3 個低價案（$200-500）→ 拿到 5 星評價
Week 3-4: 提價 50%，強調「AI 專家」+ 評價
Month 2:  再提價 30%，加入 portfolio showcase
Month 3+: 只接 $1,000+ 的案子，推月費制
```

**關鍵原則**：前 5 個案子是「買評價」，不是賺錢。評價的 ROI 遠超過低價損失。

## 綜合定價建議

### 1. 「先免費後收費」 vs 「直接收費」

| 路線 | 策略 | 理由 |
|------|------|------|
| **A: 接案** | **直接收費** | 客戶本來就預期付費，低價即可開始 |
| **B: 冷郵件** | **內部使用** | 作為獲客管道，不直接收費 |
| **C: SaaS** | **先免費後收費** | 免費方案降低試用門檻，用量成長後自然升級 |
| **D: SEO** | **先免費後收費** | 內容先免費建立流量，流量足夠後開啟 AdSense + 聯盟 |
| **E: 社群** | **先免費後收費** | 先建立受眾和信任，再推付費內容 |
| **F: Agent Pack** | **直接收費** | 專業軟體，目標客戶有明確預算 |
| **G: 托管** | **直接收費** | B2B 服務，客戶期望付費 |
| **H: 情報** | **先免費後收費** | 免費摘要建立權威，深度分析才收費 |
| **I: 開發者工具** | **先免費後收費** | 開發者偏好先試再買，Free tier 必要 |
| **J: 交易** | **先免費後收費** | 免費頻道建立信任（交易領域詐騙多） |

### 2. 最適合直接收費的路線（優先做）

```
收費難度排序（從易到難）:

1. Route A (接案)    — 最容易，市場已有付費習慣，明天就能開始
2. Route G (托管)    — B2B，客戶理解價值，導入費 + 月費
3. Route F (Agent Pack) — 產品化，一次銷售多次收入
4. Route B → C (冷郵件→訂閱) — 服務合約，需建立信任
5. Route H (情報)    — 需要展示品質
```

### 3. 價格錨定策略

#### 方案一：「三層定價」法（所有 SaaS/訂閱產品適用）

```
           ┌────────────┐
           │  Premium   │  ← 價格錨點（讓中間方案看起來划算）
           │  $199/月   │     只有 5-10% 的人會買
           └────────────┘
       ┌────────────────────┐
       │    Professional    │  ← 你真正想賣的（標記「最受歡迎」）
       │      $79/月        │     60-70% 的人會選這個
       └────────────────────┘
  ┌──────────────────────────────┐
  │           Starter            │  ← 低門檻入口
  │           $29/月             │     20-30% 的人從這裡開始
  └──────────────────────────────┘
```

#### 方案二：「損失框架」法（B2B 銷售適用）

```
銷售話術結構:

「你目前每月花 NT$60,000 在人工客服（2 人 × NT$30,000）。

 我們的 AI 客服可以處理 70% 的問題，
 你只需要 1 個人工客服 + NT$14,999 的 AI 服務。

 每月節省: NT$60,000 - NT$30,000 - NT$14,999 = NT$15,001

 年化節省: NT$180,012
 投資回報周期: 第 1 個月就回本。」
```

#### 方案三：「比較錨定」法（接案/顧問適用）

```
「台灣 AI 顧問市場行情:
 - 大型顧問公司 (PWC, 麥肯錫): NT$15,000-50,000/hr
 - 獨立高階顧問: NT$5,000-10,000/hr
 - 我的定價: NT$3,500/hr ← 看起來很划算

 而且我提供 AI 驅動的持續服務，
 不是一次性建議 — 是持續執行。」
```

### 4. 折扣和促銷時機

| 促銷類型 | 時機 | 折扣 | 目的 |
|---------|------|------|------|
| **早鳥優惠** | 產品上線首月 | 30-50% off | 快速獲得首批客戶+評價 |
| **年付折扣** | 常態 | 20%（2 個月免費） | 提高客戶留存+現金流 |
| **黑五/雙十一** | 11 月 | 40% off 年費 | 利用消費高峰 |
| **農曆新年** | 1-2 月 | 首月免費 or NT$1 | 台灣市場特有 |
| **推薦獎勵** | 常態 | 雙方各得 1 個月免費 | 低成本獲客 |
| **學生/非營利** | 常態 | 50% off | 建立口碑+社會責任 |
| **限時升級** | 季度末 | 免費升一級 30 天 | 體驗高級功能→留存 |

#### 不該給折扣的場景

```
絕對不要:
├── 客戶威脅要離開時 → 改善產品，不是降價
├── 競爭對手降價時 → 差異化，不是價格戰
├── 沒有明確到期日的折扣 → 失去緊迫感
└── 超過 50% 的折扣 → 損害品牌價值感知
```

## 附錄：定價決策速查表

### 「我該收多少？」快速判斷

```
Step 1: 客戶目前花多少解決這個問題？
        → 你的定價 = 那個數字的 10-30%

Step 2: 如果客戶目前沒花錢（新需求）
        → 找到最接近的替代方案價格
        → 你的定價 = 替代方案的 50-80%

Step 3: 如果完全沒有參考
        → 從低開始（心理門檻最低的價格）
        → 每月提價 10-20% 直到轉換率下降
        → 轉換率下降前的價格 = 你的最佳定價
```

### 各路線邊際成本一覽

| 路線 | 每單位邊際成本 | 利潤率 |
|------|-------------|--------|
| A: 接案 | ~NT$0（推理）+ 你的時間 | 80-90% |
| C: SaaS | NT$80-410/客戶/月 | 85-96% |
| D: SEO | ~NT$0/篇文章 | 95%+（扣除主機費） |
| F: Agent Pack | ~NT$0/份（數位產品） | 95%+ |
| G: 托管 | NT$850-2,800/客戶/月 | 55-85% |
| H: 情報 | ~NT$0-50/份報告 | 90%+ |
| I: 開發者工具 | NT$50-200/客戶/月 | 85-95% |
| J: 交易訂閱 | ~NT$0/訂閱者 | 95%+ |

**核心結論**：Clawtex 的本地推理架構使得所有數位產品/服務的邊際成本趨近於零，因此**定價的唯一限制是客戶感知價值**，而不是成本。這是極其有利的定價位置 — 每一塊錢的收入幾乎都是純利潤。

---

> **定價第一原則**: 寧可定高再打折，也不要定低再漲價。漲價會流失客戶，打折會贏得感激。
>
> **定價第二原則**: 你賣的永遠不是技術，是結果。客戶不在乎你用 Qwen 3 還是 Claude Opus — 他們在乎報表準不準時、客服有沒有漏接、提案有沒有中。
