## 全局回退原則

1. **不帶 P0 問題進入下一階段**
2. **回退優先於硬撐**：先回退到上一穩定狀態
3. **資料優先於直覺**：go/no-go 必須基於量化資料
4. **小範圍驗證再擴大**：A/B → 試單 → 演練 → 全量
5. **時間可延但品質不可降**
